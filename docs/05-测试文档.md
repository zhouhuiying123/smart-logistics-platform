## 本地复核命令

在 `backend` 目录运行：

```powershell
pnpm.cmd test -- --runInBand
pnpm.cmd run build
pnpm.cmd run test:tracking
```

e2e 需先创建专用测试库并把 DATABASE_URL 指向它（会话级环境变量优先于 .env，不改动文件）：

```powershell
docker exec logistics-postgres psql -U logistics -d logistics -c "CREATE DATABASE logistics_test;"
$env:DATABASE_URL = "postgresql://logistics:logistics123@localhost:5432/logistics_test"
pnpm.cmd exec prisma migrate deploy
pnpm.cmd test:e2e -- --runInBand
```

在 `frontend` 目录运行：

```powershell
pnpm.cmd run build
```

完整配送流程：初始化一个专用 PostGIS 数据库并应用迁移；创建或载入演示数据；在浏览器选择待分配订单和空闲车辆，优化路线并确认；到调度任务页依次开始和完成任务；核对订单、车辆、司机及仪表盘状态。
