## 本地复核命令

在 `backend` 目录运行：

```powershell
pnpm.cmd test -- --runInBand
pnpm.cmd run build
pnpm.cmd run test:tracking
```

在 `frontend` 目录运行：

```powershell
pnpm.cmd run build
```

完整配送流程：初始化一个专用 PostGIS 数据库并应用迁移；创建或载入演示数据；在浏览器选择待分配订单和空闲车辆，优化路线并确认；到调度任务页依次开始和完成任务；核对订单、车辆、司机及仪表盘状态。
