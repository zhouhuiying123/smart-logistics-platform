## 用例分类与口径

按验收标准第 5 条划分四类：单元测试（算法与业务规则）、接口测试（HTTP 契约与错误码）、系统测试（真实数据库全链路与浏览器手工场景）、性能测试（求解耗时与构建体积）。

单元 24 项 + 接口 11 项 = 35 项，与 Jest 报告的 7 个套件 35 项一致；e2e 的 5 项按被测层级拆入接口（3 项）与系统（2 项）。

## 缺陷记录与闭环

| 编号 | 缺陷现象 | 严重度 | 根因 | 修复与复验 |
|---|---|---|---|---|
| D-01 | 并发创建任务时车辆、司机可被重复分配 | 高 | 先查后写，存在 TOCTOU 竞态 | 改 Serializable 隔离 + 条件式 updateMany 抢占；ST-02 复验 |
| D-02 | 事务回滚后仍发出任务通知 | 中 | 通知在事务提交前发送 | 改为提交后发送；UT-02～04 复验 |
| D-03 | 地图空白，控制台报 BMapGL 未定义 | 高 | 使用了非 webgl 版 SDK 地址 | 改用 webgl 加载地址；ST-04 复验 |
| D-04 | 仪表盘平均配送耗时显示 0 | 中 | 演示数据的 COMPLETED 任务时间不在当日 | 固定为北京时间 08:30～09:30；ST-06 复验 |
| D-05 | e2e 首次运行因 AppModule 初始化超时失败 | 中 | 默认 5 秒超时不足 | testTimeout 设为 120000；ST-01、ST-02 复验 |
| D-06 | 创建订单传入 status 触发参数校验失败 | 低 | 创建 DTO 未剔除 status | 创建 DTO 不含 status，状态由 schema 默认值置为 PENDING |
| D-07 | 前端请求 /api 前缀未剥离导致 404 | 中 | Vite 代理未重写路径 | 代理增加 rewrite 剥离 /api；ST-03 复验 |

7 项缺陷均已修复并有对应复验用例，无遗留未闭环缺陷；未执行项（生产部署、鉴权、并发压力）属于范围外限制，不按缺陷计数。

## 本地复核命令

在 `backend` 目录运行：

```powershell
pnpm.cmd test -- --runInBand
pnpm.cmd run build
pnpm.cmd run test:tracking
```

e2e 需先创建专用测试库并把 DATABASE_URL 指向它（会话级环境变量优先于 .env，不改动文件）：

```powershell
docker exec logistics-postgres psql -U logistics -d logistics -c "CREATE DATABASE logistics_test;"
$env:DATABASE_URL = "postgresql://logistics:logistics123@localhost:5432/logistics_test"
pnpm.cmd exec prisma migrate deploy
pnpm.cmd test:e2e -- --runInBand
```

在 `frontend` 目录运行：

```powershell
pnpm.cmd run build
```

完整配送流程：初始化一个专用 PostGIS 数据库并应用迁移；创建或载入演示数据；在浏览器选择待分配订单和空闲车辆，优化路线并确认；到调度任务页依次开始和完成任务；核对订单、车辆、司机及仪表盘状态。
