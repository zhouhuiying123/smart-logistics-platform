## 第一部分：算法设计

### 1. 选型背景

传统 VRP 精确求解算法（分支定界、动态规划、混合整数规划）时间复杂度呈指数级增长，配送节点超过 100 后几乎不可用。因此本项目全部采用启发式遗传系列算法（CVRP-GA、VRPTW-GA、NSGA-II），用可接受的时间代价换取高质量可行解。

### 2. 主要数学公式

**Clarke-Wright 节约值**（CVRP-GA 初始解）：s(i,j) = d(0,i) + d(0,j) - d(i,j)

**VRPTW 时间推演**：
- 行驶分钟 t(i,j) = d(i,j) × 60 / (v × 1000)
- 等待 w = max(e_i - a, 0)，迟到 lt = max(a' - l_i, 0)

**VRPTW 适应度**：F = Σd_r + λ·Σlt_i，默认 λ = 1000

**自适应变异率**（200 代线性衰减）：p_m(g) = 0.15 - 0.13 × g / G

**Pareto 支配**（三目标：总距离、车辆数、总迟到）：x 优于 y 当且仅当所有目标 f_k(x) ≤ f_k(y) 且至少一个严格小于

**拥挤度距离**：crowd(i) = 对每个目标 k，累加 (f_k(i+1) - f_k(i-1)) / (f_k_max - f_k_min)

### 3. 算法参数

| 算法 | 种群 | 迭代 | 关键参数 |
|---|---:|---:|---|
| CVRP-GA | 80 | 200 | OX 交叉 0.85、自适应变异 0.15→0.02、精英保留 4、Savings 初始解、2-opt 局部搜索 |
| VRPTW-GA | 80 | 200 | 同 CVRP-GA 骨架，额外含时间窗评估与迟到罚金 |
| NSGA-II | 60 | 150 | 排列交换变异 0.15、分配变异 0.20、快速非支配排序、拥挤度选择、父子代合并 |

### 4. 时间与空间复杂度

| 组件 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 距离矩阵 | O(n²) | O(n²) |
| Savings 初始解 | O(n² log n) | O(n²) |
| 单个体解码 | O(n·m) | O(n) |
| 单路线 2-opt | O(L³·r) | O(L) |
| GA 单代 | O(P·n·m) | O(P·n) |
| **CVRP/VRPTW 整体** | **O(G·P·n·m)**（约 16,000 次评价） | **O(P·n)** |
| NSGA-II 整体 | O(G·(P·n·m + k·P²))（约 9,000 次评价） | O(P²) |

其中 P=种群、G=迭代、n=订单、m=车辆、k=3 目标。评价次数由固定超参决定，与 n 无关。

### 5. 流程概览

订单/车辆/坐标 → PostGIS ST_DistanceSphere 一次查询 → n×n 球面距离矩阵
　├─ Clarke-Wright Savings 初始解 → GA 主循环 → 逐路线 2-opt → CVRP/VRPTW 单方案
　└─ NSGA-II 主循环 → Pareto 解集
　→ 路线预览 → 确认事务 → 分配车辆/司机 → 生成调度任务 → 提交后广播通知

完整伪代码与实现细节见 [算法设计文档](03-算法文档.md)。

## 第二部分：算法实验报告

### 1. 实验范围

2026-11-12 复跑：3 合成场景 × 3 种子 × 3 算法 = 27 次。环境 v24.14.0 / Intel Ultra 5 125H。

### 2. 结果摘要

| 场景 | CVRP-GA | VRPTW-GA | NSGA-II |
|---|---|---|---|
| 6-wide（宽时间窗） | 80~112ms | 91~111ms | 57~109ms |
| 20-tight（紧时间窗） | 250~318ms | 336~353ms | 229~260ms |
| 50-tight（紧时间窗） | 882~904ms | 946~**1079ms** | 745~749ms |

- VRPTW-GA 因含时间窗评估与迟到罚金计算，最慢（1079ms）
- NSGA-II 在所有规模下最快（非支配排序只算 3 目标，不含 VRPTW 的逐订单时间推演）
- 6 单实验三算法耗时接近（距离矩阵占主导），50 单开始拉开差距
- 所有结果完整覆盖订单、满足容量约束、车辆不重复分配

### 3. 验证

27 次均通过：完整且不重复覆盖订单、重量体积容量、车辆不重复；时间窗迟到独立重算一致。
