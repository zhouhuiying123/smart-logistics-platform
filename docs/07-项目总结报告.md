# 项目总结报告

## 项目成果

项目形成了可本地运行的 Vue 3 + NestJS + Prisma + PostgreSQL/PostGIS 系统，包含：

- 客户、订单、车辆、司机基础数据的增删改查，并对有引用的数据和执行中的资源做状态保护。
- CVRP-GA、VRPTW-GA、NSGA-II 路线优化预览、方案选择、不同司机分配及事务确认。
- 百度地图展示客户点、优化预览和调度任务路线；接口坐标由 WGS84 转为百度 BD09。
- 调度任务开始、完成、取消及订单/车辆/司机状态联动。
- `/tracking` Socket.IO 命名空间发送任务状态更新，前端收到后重新查询任务。
- 运营仪表盘和空数据库演示数据脚本。

## 验证结果

最近一次本地自动检查通过：后端 7 个 Jest 套件、33 个测试；Nest 后端构建；Vue 类型检查与 Vite 生产构建；独立 Socket.IO 握手和通知传输；演示 seed 脚本语法检查。

完整数据库 e2e 和真实浏览器地图验收未在本次运行：e2e 会修改数据库，必须使用专用测试库；百度地图需要有效 AK、域名白名单和网络访问。

## 范围与限制

VRP 优化和地图路线使用球面直线距离，不生成真实道路导航路径。任务通知只含状态与资源编号，不提供 GPS 坐标、历史消息重放或实时车辆轨迹。Redis 已在 Docker Compose 中提供，但尚未接入业务。系统没有用户鉴权和公网部署，不应直接承载或公开真实业务数据。
