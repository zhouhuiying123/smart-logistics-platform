# 项目实施材料

## 实施范围

项目由 Vue 3 + Vite 前端、NestJS REST/Socket.IO 后端、Prisma ORM、PostgreSQL/PostGIS 数据库和 CVRP/VRPTW/NSGA-II 启发式算法组成。浏览器端提供基础数据管理、路线地图、任务状态流转和运营仪表盘。系统用于课程演示，不含用户登录、车辆 GPS 硬件或生产级道路导航。

## 环境准备

- Node.js 与 pnpm
- Docker Desktop（用于 PostgreSQL/PostGIS；Redis 容器暂未接入业务）
- 百度地图浏览器端 AK，网站白名单覆盖运行前端的域名

## 首次启动

1. 在项目根目录运行 `docker compose up -d postgres`。
2. 在 `backend` 将 `.env.example` 复制为 `.env`，确认 `DATABASE_URL` 指向本地数据库。
3. 在 `backend` 运行 `pnpm.cmd install`、`pnpm.cmd exec prisma generate` 和 `pnpm.cmd exec prisma migrate deploy`。迁移负责创建数据表并启用 PostGIS。
4. 在 `frontend` 将 `.env.example` 复制为 `.env.local`，设置 `VITE_BAIDU_MAP_AK`。
5. 如数据库为空，在 `backend` 运行 `pnpm.cmd run seed:demo`。脚本只对空业务库写入演示数据，不会清空已有记录。
6. 在两个终端分别运行后端 `pnpm.cmd run start:dev` 与前端 `pnpm.cmd run dev`。
7. 浏览器打开 Vite 显示的地址（默认 `http://localhost:5173`）；Swagger 在 `http://localhost:3000/api/docs`。

## 演示流程

1. 在“基础数据”检查客户、订单、车辆、司机；先建客户才能建订单。
2. 在“地图可视化”选择待分配订单和空闲车辆，运行一种算法预览路线。
3. 为每条使用中的路线分配不同的可用司机，确认方案生成调度任务。
4. 在“调度任务”依次开始、完成或取消配送；状态更新会联动车辆、司机、订单并通过 Socket.IO 通知前端。
5. 在“运营仪表盘”查看汇总。

## 已知限制

路线线段按球面距离模型绘制，不代表真实道路导航；地图显示前将接口 WGS84 坐标转换为百度地图 BD09。任务通知不含 GPS 位置，不保证断线期间的事件补发；前端重连后通过 REST 重新读取任务快照。未部署公网服务，当前无身份认证，不应暴露到互联网。
